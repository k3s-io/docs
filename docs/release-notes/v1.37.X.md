## Release [v1.37.1+k3s1](https://github.com/k3s-io/k3s/releases/tag/v1.37.1+k3s1)
<!-- v1.37.1+k3s1 -->

This release updates Kubernetes to v1.37.1, and fixes a number of issues.

For more details on what's new, see the [Kubernetes release notes](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md#changelog-since-v1370).

### Changes since v1.37.0+k3s1:

* Backports for 2026-09 [(#14631)](https://github.com/k3s-io/k3s/pull/14631)
  * Fix restore from compressed etcd snapshot #14528
  * Enable seccomp in riscv64 builds #14529
  * Use ginkgo CLI to run tests #14531
  * Bump k3s-io/api to v0.2.0 #14570
  * Servicelb multiple lbpools #14547
  * Close minio.Object after read #14580
  * Bump k3s-io/apis again #14589
  * Fix --flannel-cni-conf not reaching the embedded flannel #14598
  * Check-config: suppress colors when stdout is not a terminal #14595
  * Fix deploy controller not re-applying manifests when mtime is pinned to the epoch #14568
  * Bump etcd to v3.7.1-k3s3 for nonblocking logging support #14628
  * Bump kine to v0.17.1 #14627
* Bump helm-controller [(#14684)](https://github.com/k3s-io/k3s/pull/14684)
* Bump k3s-io/kubernetes and Go references [(#14695)](https://github.com/k3s-io/k3s/pull/14695)
* Bump cadvisor to v0.60.5-k3s1 [(#14698)](https://github.com/k3s-io/k3s/pull/14698)
* Reject anonymous access to supervisor router (spegel/pprof/metrics) [(#14701)](https://github.com/k3s-io/k3s/pull/14701)
* Improve CA hash validation [(#14705)](https://github.com/k3s-io/k3s/pull/14705)
